# Spotify Data Analysis

A small exploratory data analysis (EDA) and data visualization project on Spotify track data, built with Python.

## Overview

Cleaned and analyzed secondary Spotify track data to surface insights about song popularity and genres, using Pandas, NumPy, Matplotlib and Seaborn.

## Objectives

- Top 10 most popular songs on Spotify
- Top 10 least popular songs on Spotify
- Top 5 genres by popularity
- Additional exploratory insights into the dataset

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Datasets

- [Spotify Dataset (artists.csv)](https://www.kaggle.com/datasets/lehaknarnauli/spotify-datasets?select=artists.csv)
- [Ultimate Spotify Tracks DB](https://www.kaggle.com/datasets/zaheenhamidani/ultimate-spotify-tracks-db)

## Run locally

1. `git clone https://github.com/Ranjith-13/spotify-data-analysis.git`
2. `cd spotify-data-analysis`
3. `pip install pandas numpy matplotlib seaborn jupyter`
4. `jupyter notebook "Spotify Data Analysis.ipynb"`
